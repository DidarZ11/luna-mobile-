# Луна для Android — «Мой AI-помощник»

Голосовая помощница Луна, переписанная на Flutter. Сделана по лекции «Flutter × AI»: интерфейс → API → Backend → безопасность. Вместо OpenAI здесь Claude API.

```
Пользователь ──► Flutter (app/) ──► Backend (server/) ──► Claude API
     ▲                                 хранит ключ            │
     └──────────── ответ: Claude → Backend → Flutter ◄────────┘
```

| Папка | Что внутри |
|---|---|
| `app/` | Flutter-приложение: чат, голосовой ввод, озвучка, шар-луна, настройки |
| `server/` | Node.js + Express + `@anthropic-ai/sdk`: ключ, характер Луны (`persona.md`), голос (`tts.js`), защита |

## Запуск

**1. Сервер** (на компьютере):

```
cd server
npm install
copy .env.example .env      ← вписать ANTHROPIC_API_KEY и придумать APP_TOKEN
npm start
```

**2. Приложение:**

```
cd app
flutter run                 ← эмулятор или телефон по USB
```

Дальше в приложении: ⚙ → адрес сервера и токен → «Проверить связь».

- Эмулятор Android: `http://10.0.2.2:3000` (это адрес по умолчанию).
- Телефон: `http://<IP компьютера>:3000`, телефон и компьютер в одной Wi-Fi сети. IP — `ipconfig`, строка «IPv4». Если не подключается — разрешить Node.js в брандмауэре Windows для частных сетей.

Готовый APK: `flutter build apk --release` → `app/build/app/outputs/flutter-apk/app-release.apk`.

## Что умеет

- Чат: история (`ListView.builder`), ввод (`TextField`), отправка (`IconButton`), ожидание (`CircularProgressIndicator`).
- Потоковый ответ: текст появляется по мере генерации (SSE, `/chat/stream`); кнопка ■ останавливает генерацию. Отключается в настройках — тогда обычный `POST /chat`, как в лекции.
- Голос: микрофон или нажатие на луну → распознавание речи Android (ru-RU) → фраза отправляется сама. Ответ читается вслух целиком (кроме кода и ссылок) и начинает звучать с первого готового предложения, не дожидаясь конца ответа; следующий кусок качается, пока играет текущий. В настройках можно оставить только первые 1–2 фразы. Нажатие на говорящую луну или ■ — замолчать.
- Чаты: меню ☰ — список чатов (свежие сверху), «Новый чат», переименовать и удалить (⋮). Название — из первого вопроса. Все чаты хранятся на телефоне (`lib/chat_store.dart`).
- Контекст: в запрос уходят последние 40 реплик открытого чата, Луна помнит разговор. Новый чат начинается с чистого листа.
- Экранная часть ответа: обычный текст, **жирный** и заголовки, код из блоков ``` — моноширинным шрифтом с прокруткой.
- Характер: Маомао из «Монолога фармацевта» — сухо, коротко, с ленивой иронией (`server/persona.md`).
- Ошибки: нет сети, сервер не отвечает, неверный токен, лимит, сбой Claude — понятный текст в чате и кнопка «Повторить». Ошибки не сохраняются в истории и не уходят в контекст.

## Практическое задание лекции

| Шаг | Где сделано |
|---|---|
| 1. Flutter-проект и экран чата | `app/lib/chat_screen.dart` |
| 2. Отправка сообщений на Backend | `app/lib/api.dart` — `sendMessage` (POST `/chat`) и `streamChat` (поток) |
| 3. AI API на сервере | `server/app.js` — Claude API вместо OpenAI |
| 4. Ответ AI в интерфейсе | `MessageBubble` в `chat_screen.dart` |
| 5. Ошибки и состояние загрузки | `isLoading`, индикатор, `LunaApiException`, «Повторить» |

Плюс из слайда «Что можно добавить дальше»: история диалогов, контекст, голос, streaming, персонализация.

Безопасность со слайда 8: ключ Claude только в `server/.env` (в `.gitignore`), авторизация по `APP_TOKEN`, лимит 20 запросов в минуту с одного IP, проверка входных данных (пустое, длиннее 4000 символов, чужие роли в истории), обрыв генерации, если приложение закрыло соединение.

### Почему API-ключ нельзя хранить во Flutter?

APK — это просто архив. Его можно распаковать, и строки из скомпилированного Dart-кода достаются за минуту (`strings`, jadx, reFlutter). Запросы приложения можно перехватить прокси вроде mitmproxy и увидеть заголовок с ключом. Кто достал ключ — тратит твои деньги и лимиты, а отозвать его можно только выпуском новой версии приложения, причём старые копии продолжат его светить. На сервере ключ не покидает твою машину: приложение знает только адрес сервера и свой токен, а сервер решает, кому и сколько можно.

`APP_TOKEN` в приложении — тоже не секрет по той же причине. Это простой барьер от случайных людей в сети, а не защита. Для настоящего релиза нужны вход пользователей (например, Firebase Auth) и проверка их токена на сервере, лимиты на пользователя и HTTPS.

## Настройки сервера (`server/.env`)

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Claude API |
| `APP_TOKEN` | пусто (без проверки) | токен приложения |
| `LUNA_MODEL` | `claude-opus-5-5` | модель |
| `LUNA_EFFORT` | `low` | глубина размышлений: `low` быстрее, для голоса это важнее |
| `RATE_LIMIT_PER_MIN` | `20` | запросов в минуту с одного IP |
| `PORT` | `3000` | порт |

Если классификатор безопасности Claude отклонит запрос, API сам повторит его на запасной модели (`fallbacks: "default"`).

Сервер пишет в консоль время и токены каждого ответа: `chat/stream: 2140 мс · первый текст 1300 мс · токены: вход 1800 + кэш 0/0, выход 95`.

## Голос

Голос синтезирует сервер (`POST /tts` → mp3), приложение его проигрывает. Если сервер не смог, говорит системный голос телефона. Повторяющиеся фразы кэшируются.

| `LUNA_TTS` | Голос | Скорость (короткая фраза, замер) | Цена |
|---|---|---|---|
| `edge` | Vivienne, как у Луны на Windows | ~1.3 с | бесплатно |
| `elevenlabs` | свой голос или любой из библиотеки ElevenLabs | ~0.3–0.6 с (`eleven_flash_v2_5`) | 0.5–1 кредит за символ |

Выбрать голос:

```
npm run voices                 ← образцы edge → voice-samples/
npm run library                ← образцы женских голосов ElevenLabs → voice-samples/eleven/ (тратит кредиты)
npm run design                 ← 3 новых голоса по описанию Луны → voice-samples/design/
npm run design -- "описание"   ← по своему описанию (лучше по-английски)
npm run save-voice -- <id>     ← сохранить вариант из design как голос «Луна» и включить его в .env
```

Голос из библиотеки: вписать в `.env` `ELEVENLABS_VOICE_ID=<id>` и `LUNA_TTS=elevenlabs`. `npm run design` требует, чтобы у ключа ElevenLabs было право Voice Generation. Если ElevenLabs недоступен (кончились кредиты, нет сети), сервер переключается на edge.

## Чего нет по сравнению с версией для Windows

Слово «Луна» без нажатия (wake word), быстрые команды (будильник, громкость, открыть приложение), Telegram, снимок экрана, работа с файлами через Claude Code. На телефоне у Луны пока нет инструментов — она только разговаривает. Следующий шаг — добавить их через tool use Claude API.
